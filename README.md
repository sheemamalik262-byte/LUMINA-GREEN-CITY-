## ✨ About The Project

**Lumina Green City** is a fully responsive, multi-page website for a premium housing scheme set in Pakistan. It showcases modern web development with an elegant gold & navy design, offering users a seamless experience to explore properties, sectors, facilities, and apply for plots — all from one beautifully crafted platform.

> *"Where luxury meets community — Pakistan's next-generation residential destination."*

---

## 🚀 Getting Started

### View Live
Simply visit: **[https://sheemamalik262-byte.github.io/LUMINA-GREEN-CITY-/](https://sheemamalik262-byte.github.io/LUMINA-GREEN-CITY-/)**

### Run Locally
```bash
# Clone the repository
git clone https://github.com/sheemamalik262-byte/LUMINA-GREEN-CITY-.git

# Install Python dependencies
pip install flask

# Run the backend
python app.py

# Or just open index.html in your browser for the static version
```
